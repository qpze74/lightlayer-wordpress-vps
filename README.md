## 1核1G 够不够，2核2G 多花的钱值不值

WordPress 官方给的门槛很低，PHP 7.2+、MySQL 5.5+、512MB 内存就能装起来。真到日常使用，内存被吃掉的地方是缓存插件、备份任务、后台更新和 MySQL 缓冲池，不是 WordPress 本体。

1核1G 能撑住的场景很具体：日访客几百的文字博客，插件控制在十来个以内，配一个缓存插件。装 Elementor 这类页面构建器再叠安全插件，后台会明显变慢。

2核2G 适合日访客几千、插件装得多、或者要跑 WooCommerce 的站。LightLayer 这里有个价差值得算：洛杉矶 1核1G 是 $4/月，2核2G 是 $5.6/月，一年多花 $19.2，换到双倍内存和翻倍的带宽档位。

香港机房目前公开列表里只有 1核1G，要 2核2G 得上洛杉矶（$5.6/月）或台湾（$17/月）。台湾的 2核2G 比洛杉矶贵三倍，除非访客就在港台和东南亚，否则没必要。👉 [按 $5.6/月 开通洛杉矶 2核2G](https://account.lightlayer.net/?cmd=cart&action=add&affid=74&id=97)

硬盘这项要留个心眼。公开配置写的是 50G SSD，没有标 NVMe。NVMe 的 4K 随机读写比 SATA SSD 高一个量级，WordPress 后台、数据库查询、插件读写都吃随机 IO。50G 容量对内容站够用（本体加主题插件两百来兆，剩下都是图片和备份），但盘的类型建议下单前问一句。
